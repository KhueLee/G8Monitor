Bản đồ

Cập nhật map từ RCS: máy chủ tải map zip từ RCS, tách ảnh nền và topology (toạ độ điểm), thay toàn bộ bản đồ đang hiển thị. Map RCS thiếu ảnh nền thì xuất map từ RCS ra file zip rồi dùng Cập nhật từ file zip. Tải map về máy: máy chủ tải map từ RCS về trước, sau đó máy này kéo file về theo từng khúc (mất mạng thì tự thử lại khúc đó).

  
Highbay (mapping node ↔ tên ô)

  
Tải file Excel highbay lên: file vị trí xuất từ RCS (cột Area Name, Location Code, Node) hoặc file mapping (cột Khu, Dãy, Node, Tên RCS, Tầng 1–4). Tool bóc tách và thay toàn bộ bảng cũ bằng file mới nhất, để vị trí robot, điểm task, vị trí lỗi hiện theo tên ô người vận hành quen dùng (vd. D36-12).
